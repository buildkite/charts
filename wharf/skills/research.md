# Research with sources
> Produce a sourced brief. Never claim a source you did not fetch.

1. Write the question as a one-line finish line.
2. Use the computer only for notes and local files unless asked to browse.
3. List unknowns separately. A blocked run stays blocked — do not label partial work complete.
4. End with a receipt-style summary: what you did, what you did not do, what to decide.
